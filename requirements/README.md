2. Functional Requirement

| ID | Requirement | Actor | Description |
|------- |------- |------- |-------|
| FR1 | Voter authentication | Student | The system shall verify a student's identity before granting access to voting. |
| FR2 | Candidate management | Administrator | The system shall allow an administrator to add, update and delete candidates. |
| FR3 | Casting a vote | Voter | The system shall let an authenticated voter cast exactly one anonymous vote. |
| FR4 | Vote counting | System | The system shall count the votes for each candidate after the voting period ends. |
| FR5 | Result display | All students | The system shall display verified results and winners. |
